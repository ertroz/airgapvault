Start from Scratch

What does a new user do first?

Select your operating system to install the airgapvault binary, then follow the 4 steps below to migrate your plaintext .env files into an encrypted vault.

STEP 01

Initialize Your Vault

Create an encrypted vault at ~/.airgapvault/vault.agv protected by a master passphrase (confirmed twice, masked input).

airgapvault init
STEP 02

Import & Remove Plaintext .env

Migrate an existing .env file into a project/env namespace and automatically delete the plaintext source file.

airgapvault import myapp/dev .env --delete-source
STEP 03

Add New Secrets Safely

Omit =VALUE to enter secrets interactively without echoing them to the terminal or leaving traces in shell history.

airgapvault set myapp/prod API_SECRET
STEP 04

Run Apps Without .env

Decrypt secrets in memory only, inject them directly into the child process environment, and forward signals and exit codes.

airgapvault run -p myapp -e dev -- npm run dev
Security Architecture

Built for isolated environments

Every design choice prioritizes cryptographic integrity, deterministic behavior, and zero network reliance.

Argon2id + AES-256-GCM

Master passphrases are derived via Argon2id (64 MiB, 3 iterations). Ciphertext and header metadata (AGV1) are authenticated together via AAD to reject tampering.

Atomic Writes & Fresh Nonces

Every vault update generates a fresh random salt and nonce, writes to a 0600 temp file, calls fsync, and atomically renames it to prevent corruption on crash.

Offline Automation via Keyfiles

For airgapped CI pipelines or non-interactive containers, unlock vaults deterministically using --keyfile <path> and AIRGAPVAULT_FILE.

CLI Commands

Filter below to find any command or flag.

Command Description
airgapvault init [--force] Create a new encrypted vault with a master passphrase (2x confirmation) or --keyfile.
airgapvault set <proj>/<env> <KEY>[=<VAL>] Add or update a secret. Omit =<VAL> for masked interactive input.
airgapvault get <proj>/<env> <KEY> Print a single secret value to stdout (omits trailing newline when piped).
airgapvault list [<proj>[/<env>]] [--reveal] List projects, environments, or keys. Pass --reveal to display secret values.
airgapvault rm <proj>[/<env> [<KEY>]] [-y] Remove a key, an entire environment, or an entire project (prompts for confirmation).
airgapvault import <proj>/<env> <.env> [--delete-source] Import an existing .env file (supports comments, export, quotes) and optionally delete the source file.
airgapvault run -p <proj> -e <env> -- <cmd...> Decrypt in memory, inject secrets into child process env, and forward SIGINT/SIGTERM and exit code.
airgapvault export <proj>/<env> --format dotenv Manual fallback to print .env formatted secrets to stdout.
airgapvault passwd [--new-keyfile <path>] Rotate the master passphrase or keyfile and re-encrypt the vault.
